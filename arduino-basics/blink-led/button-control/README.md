 Button Controlled LED (Arduino Project)

 Description
This project demonstrates how to control an LED using a push button.

- When button is pressed → LED ON
- When button is released → LED OFF

Components
- Arduino board
- LED
- Push button
- Resistor
- Breadboard
- Jumper wires

Pin Configuration
- Button → Pin 2
- LED → Pin 3
